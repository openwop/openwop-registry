# core.openwop.workflows.customer-onboarding

RFC 0013 workflow-chain pack (3 chains) — part of the ADR 0190 evidence-based template catalog. Source of truth: the openwop-app repo, examples/workflow-chain-packs/. Customer-onboarding chains (RFC 0013): the post-sale first-mile — a warm welcome, a personalized kickoff checklist, and a scheduled 30-day health check. All external sends sit behind a human approval gate; tenant values are run parameters (replay-deterministic).
