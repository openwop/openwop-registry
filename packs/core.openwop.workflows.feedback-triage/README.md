# core.openwop.workflows.feedback-triage

RFC 0013 workflow-chain pack (2 chains) — part of the ADR 0190 evidence-based template catalog. Source of truth: the openwop-app repo, examples/workflow-chain-packs/. Feedback-triage chains (RFC 0013): turn raw inbound feedback into classified, routed, actionable items. A form submission is classified and (on approval) filed as a follow-up task; a batch is themed into a weekly digest. Replay-deterministic.
