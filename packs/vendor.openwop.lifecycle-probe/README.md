# vendor.openwop.lifecycle-probe

A probe pack for the v2 registry lifecycle ([RFC 0222](https://github.com/openwop/openwop/blob/main/RFCS/0222-v2-registry-operations.md)). Version 1.0.0 is published and then yanked through the `[YANK]` pull-request flow in `docs/runbooks/PACK-LIFECYCLE.md`, so `v2-registry-lifecycle.test.ts` has a real yanked version to read. Version 1.0.1 is the unyanked latest.

It carries one placeholder prompt. Do not install it.
