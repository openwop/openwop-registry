# core.openwop.workflows.starters

RFC 0013 workflow-chain pack (6 chains) — part of the ADR 0190 evidence-based template catalog. Source of truth: the openwop-app repo, examples/workflow-chain-packs/. Starter workflow pack (RFC 0013, ADR 0190) — the simple-pipe on-ramp tier: short single-trigger→action recipes (webhook→notify, form→table, schedule→digest, fetch→store) that run in under a minute with zero connections, before you graduate to the AI-agent packs.
