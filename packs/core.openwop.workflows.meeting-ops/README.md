# core.openwop.workflows.meeting-ops

RFC 0013 workflow-chain pack (2 chains) — part of the ADR 0190 evidence-based template catalog. Source of truth: the openwop-app repo, examples/workflow-chain-packs/. Meeting-ops chains (RFC 0013): less time in and around meetings — an agenda from a stated goal, and notes turned into owned action items. In-app and draft sinks only; replay-deterministic.
